# PowerShell Runner

PowerShell Runner is a Windows desktop application designed to make working with PowerShell scripts simpler and more convenient.

Instead of running scripts directly from a terminal every time, PowerShell Runner provides a graphical environment for launching scripts and working with their execution.

## Features

- Run PowerShell scripts from a graphical interface
- Simple and clean Windows UI
- Execution feedback and output
- Convenient script management
- Native Windows application
- Built with .NET 10 and WPF

## Requirements

- Windows 10 or Windows 11
- .NET 10 Desktop Runtime
